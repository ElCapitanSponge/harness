# A declined approval ends the turn

When the owner declines a change in a coding session, the turn stops instead of returning the refusal to the model to try something else. Local models retried a declined write about fifteen times in testing, which wastes time and nags the owner. Auto-approval exists only as an explicit opt-in flag.
